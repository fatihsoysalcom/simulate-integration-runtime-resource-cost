# Simulate Integration Runtime Resource Cost

This Python script simulates an on-premise data integration task to demonstrate server resource consumption. It performs CPU-intensive data transformations and writes processed data to a file, illustrating how workload parameters affect execution time and I/O. Users can observe CPU, memory, and disk I/O spikes during execution, reflecting the 'real cost' discussed in the article.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`.
3. Observe system resource usage (CPU, Memory, Disk I/O) using tools like `htop` or Task Manager.
